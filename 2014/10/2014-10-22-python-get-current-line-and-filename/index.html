Python 获取当前执行文件名和行数

Oct 22, 2014
阅读时长: 1 分钟

这个发现是 logger 或者 traceback 是有这个功能的，所以简单的研究了一下，其实很简单：

#!/usr/bin/env python
# -*- coding: utf-8 -*-

import sys

print sys._current_frames().values()[0].f_code.co_filename,
print sys._current_frames().values()[0].f_lineno

执行结果如下：

printno.py 7
